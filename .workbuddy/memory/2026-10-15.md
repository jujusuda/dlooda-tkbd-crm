## 复用坑（本次新踩）
- python-pptx 1.0.2 里 `shape.adjustments = x` 会抛 AttributeError（can't set attribute）→ 用 `shape.adjustments[0] = x`，或干脆不设（默认 roundRect 弧度即可）。
- 校验 rels 时路径解析要按 OPC 规则：`dir/_rels/x.rels` 的基准目录是 `dir`（不是 `dir/_rels`），否则根目录 `_rels/.rels` 与 `ppt/_rels/presentation.xml.rels` 会全部误报失效。
- SVG 预览换算：幻灯片 13.333×7.5in → 680px 宽时 1in=51px、1pt=0.7083px；字号不要用 `pt*4`，必须是 `pt*12700`（EMU）否则文字小到看不见。
