## 修复：今日视频不显示 + 寄样任务总计看不到（用户反馈"还是没有"）

### 根因1：日历跑到数据前面（视频/寄样/邀约今日全空）
- 实时时钟 8/11，但飞书数据只同步到 8/10（视频时间最新 8/8、sampleTime 最新 8/9、invite 最新 8/10）。
- 原 `getDailyReportData` 用 `getTodayStr()`（实时今天）做匹配 → 今日寄样/视频/邀约全部 0。
- **修复**：新增 `getDataToday()` —— 实时今天在数据里有活动就用实时今天；否则回退到 `max(最新sampleTime, 最新invite date)`（数据最新业务日）。日报"今日"锚定到它，视频再 T-2。
- 实测：锚定到 8/10 → 视频时间 8/8 → 19 个视频正常显示；今日寄样 21、邀约 4。
- 新增 `todayAnchored` 标记，界面标注「数据最新日 X，实时今天 Y 暂无数据」，避免用户以为统计错。
- **设计原则（重要）**：日报工具的"今日"应锚定数据最新日，而非实时时钟——否则任何时钟漂移都会让"今日"空白。

### 根因2：用户看不到已提交的改动（任务总计/视频修复）
- 上一轮已写好转码+总计代码并提交 97b0934，但用户仍看不到。
- 真凶：**sw.js 之前改成所有文件 stale-while-revalidate（缓存优先）** → 浏览器 reload 时先返回旧缓存 JS，新代码要第二次 reload 才生效，用户卡在旧版。
- **修复**：sw.js 改混合策略——`js/real-data.js`（2.8MB，只随同步变）仍缓存优先+后台刷新；其余 html/css/js 改**网络优先**，代码改动刷新即生效。CACHE_VERSION 升 v7。
