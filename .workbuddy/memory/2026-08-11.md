### 根因1：日历跑到数据前面（视频/寄样/邀约今日全空）
- 实时时钟 8/11，但飞书数据只同步到 8/10（视频时间最新 8/8、sampleTime 最新 8/9、invite 最新 8/10）。

- 实测：锚定到 8/10 → 视频时间 8/8 → 19 个视频正常显示；今日寄样 21、邀约 4。
- 新增 `todayAnchored` 标记，界面标注「数据最新日 X，实时今天 Y 暂无数据」，避免用户以为统计错。
- **设计原则（重要）**：日报工具的"今日"应锚定数据最新日，而非实时时钟——否则任何时钟漂移都会让"今日"空白。

## 第二轮修复（用户又反馈"视频没条数 + 计划条数改达人数 + 日期不能选以后"）

### 视频再加 fallback（双保险）
- 即使锚定到数据最新日，若 `today-2` 当天恰好无视频（数据缺口），原逻辑仍显示 0。
- 新增：若 `today-2` 匹配数为 0，自动回退到数据里**最新视频日期**再匹配一次。保证「今日视频」永远有最新一批，不会空白。实测 8/8 的 19 个视频正常显示。

### 邀请达人数口径（用户拍板）
- 飞书「邀约达人」表是**计划维度**（每行一个SKU邀约计划：日期/SKU/品类/佣金/计划/达成），`creatorId` 全部为空 → 无法按达人去重算真·达人数。
- 用户三选一选了「用触达人数(人)」：日报邀约卡片改为「今日邀约达人数 = 今日各邀约计划 achieved 累计（今日 18940 人）/ 4 个计划」。STAT_DEFS invite 项 label 改为「今日邀约达人数」，autoKey=todayInviteReach(人)，subKey=todayInviteCount(个计划)。

### 全模块日期限制"今天及以前"
- 用户要求所有时间选择器不能选今天以后。
- app.js createFilterBar：开始/结束日期 input 加 `max=getTodayStr()`，本月/近7天动作结束日不超过今天（已覆盖 dashboard/sample/report/invite/message/product/video/creator/ai-assistant 等所有筛选栏）。
- daily.js：日报日期 input `max=今天` + 后翻按钮若已在今天则禁止再后翻。
- todo.js：待办日期 input `max=今天` + 后翻按钮 forbid 越过今天。
- 注意：仅设 `max` 不够——后翻/前进按钮仍能跳到未来，必须同时 guard 按钮。

### 又发现：用户一直跑在旧缓存（关键坑）
- 用户截图仍显示 2026-08-09（pre-anchor 旧版），说明 v7 SW 没接管。
- 根因：虽然 sw.js 已有 skipWaiting + clients.claim、app.js 有 controllerchange→reload，但 **CACHE_VERSION 没升**，reg.update() 拿到的是同字节 sw.js，不触发新 SW 安装 → 旧 SW 继续服务旧缓存 JS。
- **修复**：CACHE_VERSION 升 v8，强制 SW 重新安装→接管→controllerchange→自动 reload，下一轮加载即拿到最新代码。
- **经验（重要）**：每次改了 JS/CSS 且要用户立刻看到，**必须 bump CACHE_VERSION**（即使 sw.js 逻辑没变，version 字符串变了 = 字节变了 = 触发更新）。
